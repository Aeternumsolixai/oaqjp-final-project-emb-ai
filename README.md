# Emotion Detection Web Application

Final project from the IBM Generative AI Engineering Professional Certificate.

A simple web application that detects emotions (anger, disgust, fear, joy, sadness) from text input using a pre-trained emotion detection model.

## Features
- Text input for emotion analysis
- Returns the dominant emotion and confidence scores
- Clean web interface built with Flask
- Includes unit tests

## Technologies Used
- Python
- Flask
- EmotionDetection package (IBM Watson NLP / related emotion model)
- HTML / CSS (templates + static files)
